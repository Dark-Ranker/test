# 🎂 Your Special Day — Nguyễn Trương Tuệ Nhi (17/11)

Trang web chúc mừng sinh nhật tuổi 18 dành riêng cho **Nguyễn Trương Tuệ Nhi (17/11)** với hiệu ứng bầu trời sao 3D, trái tim Neon pha lê, thiệp mở 2 trang thơ cài tên thất ngôn bát cú, nhạc nền đồng bộ lời Karaoke và màn pháo hoa nghệ thuật 2K QHD.

## 🚀 Cách đưa lên GitHub Pages (Chạy Online miễn phí)

1. Tạo một Repository mới trên GitHub (ví dụ: `tue-nhi-18th-birthday`).
2. Tải các file trong gói này lên Repository:
   - `index.html` *(File chạy chính cho GitHub Pages)*
   - `preview-18th-birthday.jpg` *(Ảnh nền 2K QHD sắc nét)*
   - *(Tuỳ chọn)* Nếu bạn có file nhạc `.mp3` bản thu đầy đủ `03:24` của bài **"Birthday Xinh Iu - Lập Nguyên"**, hãy đổi tên file nhạc thành **`birthday-xinh-iu.mp3`** và tải lên cùng thư mục với `index.html`. Trang web sẽ tự động nhận diện và phát file `birthday-xinh-iu.mp3` kèm lời Karaoke Full bài!
3. Vào mục **Settings** của Repository $\rightarrow$ chọn **Pages** ở thanh menu bên trái.
4. Tại mục **Build and deployment** $\rightarrow$ **Branch**, chọn nhánh `main` (hoặc `master`) và thư mục `/(root)` $\rightarrow$ bấm **Save**.
5. Đợi khoảng 1 phút, trang web của bạn sẽ hoạt động tại địa chỉ:
   `https://<tên-tài-khoản-github>.github.io/<tên-repository>/`

## ✨ Các tính năng chính
- **Đếm ngược đến 18:30 ngày 17/11** & Mật mã mở quà `1711` (có nút bật/tắt Quyền truy cập tạm thời để xem trước).
- **Trái tim Neon & Vòng xoay Pha lê 3D** trên nền trời sao lấp lánh toàn màn hình.
- **Thiệp sách 2 trang**: Trang trái cố định với ảnh Polaroid & bài thơ thất ngôn bát cú cài tên *Nguyễn · Trương · Tuệ · Nhi*; trang phải cuộn mượt mà với bức thư chúc mừng.
- **Nhạc nền & Lời bài hát đồng bộ ("Birthday Xinh Iu - Lập Nguyên")**:
  - Tự động phát bản Full `03:24` (qua YouTube Topic Audio trên GitHub Pages hoặc file `./birthday-xinh-iu.mp3`), kèm nút tinh chỉnh độ khớp lời (`-0.5s` / `+0.5s`) và thanh tua nhanh trong mục **`📜 Full Lời & Nhạc`**.
- **Màn kết Pháo hoa nghệ thuật & Mưa hoa anh đào 3D**:
  - Đếm ngược `3 - 2 - 1 - 0` mở ra bức tranh cổ trang đêm trăng 2K QHD (`2560x1440`), chữ thư pháp trên 2 dải cờ phát sáng kim quang, vòng tinh tú xoay quanh số `18`, pháo hoa đa tầng và 135 cánh hoa anh đào rơi 3D.
